title: "Document Structure"
---

A MarkVSpec document keeps readable Markdown and structured DSL sections in the same file.

## Roles

- Prose explains the screen purpose and product decisions for human readers.
- Structured sections such as `## States`, `## Layout`, `## Elements`, and `## Actions` drive preview and validation.
- Use [Reference](/markvspec/en/reference/) when you need exact syntax.

## Writing Order

1. Write the screen purpose briefly.
2. Name the states.
3. Add layout and elements.
4. Add actions, validations, and scenarios as needed.
5. Check the result in VS Code preview.

Related: [Markdown Model](/markvspec/en/guide/markdown-model/)
