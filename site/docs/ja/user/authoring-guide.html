Marker と参照

ID chip は prose、marker、source ID をつなぐ

#{ID} 
## Notes

Review the required email behavior in #{E-EmailInput}
before changing #{A-SubmitLogin}.

### E-EmailInput Input
- label: Email

Review the required email behavior in E-EmailInput before changing A-SubmitLogin.

E1 E-EmailInput
Email
  • #{ID} は screen、layout、element、action、rule、validation ID への prose reference です。
  • preview は prose 内の compact reference chip と、visual element 付近の marker を表示できます。
  • marker はレビュー補助です。author が低レベルな layout 指示を書く理由にはしません。

HTML/PDF 出力

HTML/PDF export はレビュー相手と共有するための出力形式です。static HTML renderer は、 source ID、生成セクション、wireframe、display result など、authoring intent を読める形で残します。 コマンド、ブラウザ要件、印刷時の挙動は PDF 出力と共有 を参照してください。
サンプルギャラリー`examples/` の実 screen、template、partial を開いて確認します。 DSL リファレンス正確な syntax と validation rule が必要なときに使います。 PDF 出力static HTML と PDF output をレビュー相手に共有します。
