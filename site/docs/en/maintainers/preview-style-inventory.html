MarkVSpec Preview Style Inventory

Primary Areas

AreaWhat to Check
ToolbarSticky offset, button grouping, marker toggles, refresh controls, and table-of-contents toggle.
Table of contentsDesktop side navigation and inline document navigation.
Document basicsScreen title, metadata rows, state headings, IDs, and status labels.
Labels and badgesState, trigger, tone, repeated, marker, partial, and reference-status labels.
TablesGenerated spec tables, empty states, code tokens, and wrapping behavior.
WireframesCore renderer defaults, preview overrides, marker visibility, and print readability.
Detail blocksAction details, process cards, notes, Mermaid, and diagnostics blocks.
Responsive / printViewport-dependent layout and PDF page-break behavior.

Selector Checklist

Selector FamilyReview Focus
.toolbar, .control-label, .segmented buttonOperation controls should stay readable above the scrollable preview.
.mm-doc-label, .state-badge, .screen-reference-statusSmall labels should not overpower the generated document text.
.mm-marker-*Layout / Element / Action markers should remain distinguishable in screen and print contexts.
.spec-table, .spec-empty, codeGenerated tables, empty messages, and code tokens should wrap without overlap.
.mm-layout, .mm-elementWireframes should remain low fidelity while preserving structure.
.action-detail, .process-card, .note-contentDetail blocks should be scannable and avoid nested-card visual noise.
