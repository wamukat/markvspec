Candidate Boundaries

Use alternatives for now

Breadcrumb and Pagination should be written with row layouts, links, buttons, and page text until dedicated semantics are defined.

Not canonical yet

Generic Menu, DropdownMenu, ProgressBar, Stepper, and Skeleton remain candidates. Do not copy candidate syntax from notes as production DSL.
