# IDs

## Prefixes

MarkVSpec の ID は対象種別を読み取れる prefix を使います。

- `SCR-*`: screen
- `L-*`: layout group
- `E-*`: element
- `A-*`: action
- `R-*`: rule

## 使い方

ID は参照のための安定した名前です。表示 label とは分けて管理します。
