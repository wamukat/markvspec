# Sections

## Recognized Sections

MarkVSpec は次の section を認識します。

- `## States`
- `## Layout`
- `## Elements`
- `## Actions`
- `## Rules`
- `## Notes`
- `## Open Questions`

## 見出し

Markdown 見出しは object 宣言です。section の下で `###` 見出しを使い、必要に応じて `#### Items` などの subsection を置きます。
