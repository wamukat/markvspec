# Limitations

## 現時点の制限

- MarkVSpec は visual design tool ではなく、text-first の screen specification format です。
- Markdown table は canonical source ではありません。
- JSON は authoring format ではありません。
- CSS class、raw color、width、height などの実装詳細は primary DSL では扱いません。
