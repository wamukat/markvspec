# Markdown Model

MarkVSpec uses Markdown as the source of truth. YAML Front Matter holds document metadata, Markdown headings declare screen objects, and bullets describe properties and behavior.

## Minimal Example

```markdown
---
id: SCR-HELLO
title: Hello Screen
---

# Hello Screen

## States

### idle

## Layout

### L-Main Main

- column

## Elements

### E-Title Heading

- level: 1
- text: Hello
```
