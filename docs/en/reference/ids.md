# IDs

## Prefixes

MarkVSpec IDs use prefixes that show the target type.

- `SCR-*`: screen
- `L-*`: layout group
- `E-*`: element
- `A-*`: action
- `R-*`: rule

## Usage

IDs are stable names for references. Keep them separate from display labels.
