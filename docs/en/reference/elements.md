# Elements

## Purpose

`## Elements` describes UI elements by meaning. Prefer type, label, value, variant, tone, and action over visual implementation details.

## Example

```markdown
### E-SignInButton Button

- label: Sign in
- variant: primary
- action: A-SubmitLogin
```

## Principles

- Use `Heading` with `level: 1..6` for headings.
- `variant` means priority. `tone` means semantic intent.
- Do not write raw color, CSS class, width, or height.
