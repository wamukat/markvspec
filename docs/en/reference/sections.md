# Sections

## Recognized Sections

MarkVSpec recognizes these sections.

- `## States`
- `## Layout`
- `## Elements`
- `## Actions`
- `## Rules`
- `## Notes`
- `## Open Questions`

## Headings

Markdown headings declare objects. Use `###` under sections, with subsections such as `#### Items` where needed.
