# MarkVSpec Examples

The examples are organized as a learning path. Open them in order when checking
the DSL, preview, State Views, Action Details, and export output.

- `01-basics/hello-screen.vspec.md`: minimum screen with one state and one viewport.
- `01-basics/login-basic.vspec.md`: form layout, validation feedback, and auth states.
- `02-states/async-loading.vspec.md`: request send state, response handling, empty and error states.
- `02-states/model-samples.vspec.md`: list-first Model Samples with supplemental empty table syntax.
- `02-states/responsive-profile.vspec.md`: mobile and desktop layouts for the same states.
- `03-actions/event-triggers.vspec.md`: non-click element events and lifecycle triggers.
- `03-actions/form-submit-flow.vspec.md`: validate, model update, server call, and navigation.
- `03-actions/single-field-validation.vspec.md`: single-field validation contracts and input constraints.
- `03-actions/parallel-initial-load.vspec.md`: parallel server calls and final Resolve.
- `04-real-world-screens/notice-detail.vspec.md`: Display Content Spec fields for wording, data sources, formatting, values, and navigation params.
- `04-real-world-screens/profile-edit-rich.vspec.md`: extended form, media, list, and dialog element types.
- `04-real-world-screens/search-list.vspec.md`: search, filtering, pagination, empty result, and row action.
- `05-reuse/template-shell.vspec.md`: template shell, slot, and reusable layout basics.
- `05-reuse/profile-page-with-template.vspec.md`: template composition, route params, and partial refresh.
- `05-reuse/profile-summary.partial.vspec.md`: partial route and partial-local states.
- `06-structured-sections/history-and-errors.vspec.md`: Error Codes, History Fields, and History.
